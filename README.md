# ThreeCode Agenda

**Sistema de gestão de agendamentos para clínicas de estética.**

O ThreeCode Agenda é um projeto desenvolvido pela ThreeCode com o objetivo de facilitar a organização e o gerenciamento de agendamentos, profissionais, serviços, clientes e unidades de atendimento.

## Objetivo do projeto

Desenvolver uma aplicação web profissional, segura e escalável, que permita às clínicas de estética administrar suas operações de agendamento em um ambiente centralizado.

## Funcionalidades planejadas

- Gerenciamento de usuários e permissões.
- Cadastro e gerenciamento de profissionais.
- Cadastro de serviços e procedimentos.
- Gerenciamento de unidades.
- Cadastro e consulta de clientes.
- Agendamentos e controle de horários.
- Histórico de atendimentos.
- Relatórios e integração com Power BI.
- Painel administrativo da ThreeCode.

*As funcionalidades serão implementadas progressivamente, conforme o planejamento do projeto.*

## Tecnologias planejadas

| Área | Tecnologia |
|---|---|
| Backend | Python + FastAPI |
| Banco de dados | MySQL |
| ORM | SQLAlchemy |
| Validação | Pydantic |
| Migrações | Alembic |
| Frontend | HTML5, CSS3 e JavaScript |
| Testes | Pytest |
| Versionamento | Git e GitHub |
| Prototipação | Figma |
| Business Intelligence | Power BI |

## Segurança

O desenvolvimento seguirá os princípios de Security by Design, considerando:

- Autenticação e autorização.
- Proteção de senhas.
- Isolamento de dados entre empresas.
- Validação de informações.
- Proteção contra vulnerabilidades comuns.
- Auditoria e registro de atividades.
- Backups e recuperação de dados.
